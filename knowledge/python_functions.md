# Python函数

定义函数是在描述一段以后可以调用的代码。
调用函数时，函数体才会执行。

参数用于接收调用方提供的数据。
return用于把结果交给调用方；没有显式返回值时，普通函数返回None。

用 def 关键字写定义时，只是"写好一份说明"，函数体不会立即运行；只有用函数名加括号调用时，函数体才真正执行。

参数是函数从外部拿到输入的入口。例如 task_db.create_task 定义了 title、completed、priority 三个参数，调用时再传入具体的标题和完成状态。

return 会让函数在这一点结束，并把结果交回调用处。同一个函数可以定义一次、调用多次。
