# 工具调用

工具调用（function calling）让模型在需要时提出"调用某个工具"，而不是直接编造答案。整个过程分三步：

1. 模型提出调用：模型收到问题后返回一个工具调用请求，包含工具名和参数，例如 query_tasks、{"completed": false}。这只是"我想查询未完成任务"的意图。

2. Python执行：程序根据工具名在注册表里找到对应函数，校验参数后真正执行。例如 query_tasks 会读取 SQLite 并筛选。模型不直接运行代码、也不直接访问数据库，实际执行由 Python 完成。

3. 工具结果回传：程序把执行结果包装成 tool 消息，连同之前的对话一起再次发给模型。模型依据这个真实结果组织最终回答。

关键点：模型只负责"提出调用什么、传什么参数"，真正执行、查库、校验都在程序里；结果回传后模型基于真实数据回答，而不是凭空编造。
