# HTTP状态码在本项目中的使用

200 表示请求成功，服务端返回正常结果。例如 GET /tasks 返回任务列表，GET /health 返回状态 ok。

422 表示请求体校验失败。FastAPI 用 Pydantic 校验请求体，标题为空或超长时自动返回 422；查询助手接口里 goal 为空时也会主动返回 422。

502 表示后端调用模型服务失败，或模型返回不可用结果。本项目把模型网络错误（RequestException）和业务异常（ValueError）统一转成 502，提示"暂时无法生成有效建议"或"暂时无法完成任务查询"。

504 表示模型服务响应超时。捕获 requests.exceptions.Timeout 后转成 504，提示"模型服务响应超时，请稍后重试"。

区分：422 是请求本身不对，502 是模型服务失败或结果不可用，504 是模型响应超时。请求参数校验失败时，FastAPI可以自动返回422；接口代码也可以主动抛出HTTPException，返回约定的错误状态码。200通常在正常返回结果时产生。
